RAG Simulator

Understand how Retrieval-Augmented Generation (RAG) works step-by-step. This simulator visually demonstrates how documents are chunked, converted into vectors, retrieved using semantic similarity, and finally used by an LLM to generate answers.

1

Document Input

Knowledge base documents are provided to the RAG system.

2

Chunking

Large text is split into smaller meaningful chunks.

3

Embeddings

Each chunk is converted into vectors using embedding models.

4

Retrieval

User query vector searches for semantically similar chunks.

5

Generation

LLM uses retrieved context to generate the final answer.

How RAG Works:

Traditional LLMs rely mainly on their training data. RAG improves this by retrieving external knowledge before generating answers. This makes responses more accurate, contextual, and up-to-date.
